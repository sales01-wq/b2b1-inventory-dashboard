구글시트 자동 연결

Apps Script를 웹 앱으로 배포해두면, 헤더의 🔄 새로고침 버튼 한 번으로 그 웹앱을 통해 최신 데이터를 바로 가져옵니다. 아래 파일 업로드는 이 방법 대신 쓰거나, 이 방법이 안 될 때 백업용으로 쓰시면 됩니다.

Apps Script에서 "배포 → 새 배포 → 웹 앱 (액세스 권한: 모든 사용자)"로 배포하면 생기는 주소입니다.

CSV / 엑셀 업로드 (백업용 수동 업로드)

구글 시트에서 CSV로 각 탭을 내려받아 올리거나, 엑셀 파일(.xlsx)을 통째로 다운받아 올려도 됩니다 — 엑셀 파일 안에 시트가 여러 개 있어도 자동으로 각 시트를 인식합니다.
파일 이름과 상관없이 내용을 보고 자동으로 어떤 탭인지 인식합니다 (가용재고조회 / 제품일정표 / 일자별판매실적분석 / 유통기한(선택) / 상품마스터(선택)).
한 번 데이터를 올린 뒤에는, 바뀐 파일만 다시 올리면 됩니다 — 예를 들어 가용재고조회만 새로 올리면 나머지(제품일정표, 판매실적 등)는 이전에 올린 데이터가 그대로 유지됩니다.

거래처별 · 분기별 판매실적

품목을 행으로, 분기를 열로 나열한 표입니다. 거래처/품번을 여러 개 선택해서 비교할 수 있습니다.

품목별 판매현황

품번(SKU)이나 품명을 검색해서 선택하면, 그 품목(들)을 거래처별·월별로 얼마나 팔았는지 표로 보여줍니다. 여러 품번을 줄바꿈이나 쉼표로 구분해서 붙여넣고 Enter를 누르면 검색된 품번이 모두 합산되어 바로 선택됩니다. (여러 줄을 입력만 하고 싶을 땐 Shift+Enter)

분기별 발주 예측 (거래처별 발주 패턴 기반)

바코드 · 품명 · 거래처로 품번 / 재고 / 입고예정 조회

PO에 찍힌 바코드나 대략적인 품명을 입력하면, 해당 거래처에 실제로 출고했던 품번·품명과 현재 창고별 가용재고, 입고예정 일정을 함께 보여줍니다. 바코드/품명 둘 다 여러 개를 한 번에 넣을 수 있습니다. (성분에디터/밀크터치/마미케어 품번만 검색됩니다)
